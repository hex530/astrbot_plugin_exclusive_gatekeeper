# AstrBot 智能门禁系统 (Exclusive Gatekeeper)

本插件为 AstrBot 提供了一个强大的私聊管理方案。通过拦截陌生人消息并向管理员请示，实现高效、智能的社交管理。

## 核心特性

- **三档审批机制**：
  - **准许**：将用户加入白名单，后续消息直接放行。
  - **拒绝**：将用户加入黑名单，后续消息直接拦截（无提示）。
  - **观察**：不改变状态，下次该用户发言仍需请示。
- **LLM 智能汇报**：配合大语言模型，机器人会以拟人化的语气向管理员汇报访客信息。
- **防骚扰模式**：支持设置拦截阈值，当访客连续发送消息时自动回复提示语。
- **身份自动识别**：自动过滤无效 ID、系统通知及空消息，确保汇报内容的纯净。

## 安装方法

1. 在 AstrBot 插件管理中搜索 `exclusive_gatekeeper` 或通过本仓库 URL 安装。
2. 重启 AstrBot。

## 审批指令

当机器人向你汇报访客信息后，你只需在私聊中回复以下指令：

- `准许 [QQ号]`：将该用户设为白名单。
- `拒绝 [QQ号]`：将该用户设为黑名单。
- `观察 [QQ号]`：维持现状。
- *提示：如果直接回复“准许/拒绝/观察”（不带 QQ 号），则默认审批最后一位请示的访客。*

## 配置项说明

| 配置项 | 说明 | 示例 |
| :--- | :--- | :--- |
| `admin_qqs` | 管理员 QQ 列表（逗号分隔）。 | `1591793025` |
| `intercept_msg` | 被拦截时的自动回复。 | `主人忙碌中，请留言。` |
| `threshold` | 触发自动回复的消息条数。 | `3` |
| `use_llm_ask` | 是否开启 LLM 汇报。 | `true` |
| `ask_prompt` | 汇报时的 Prompt 模板。 | `见默认值` |
