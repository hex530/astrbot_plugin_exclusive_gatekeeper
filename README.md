# 超级门禁 (Exclusive Gatekeeper)

**作者**: 陆渊 & 夕小柠
**版本**: 2.4.5 (稳定版)

### 核心功能
通过黑白名单和三档审批机制，实现对陌生私聊消息的智能拦截与请示。

### 工作逻辑
1. **自动识别**: 自动识别并过滤无效 QQ 号、空消息及系统通知（如点赞名片）。
2. **拦截机制**: 
   - **黑名单**: 直接拦截，不进行任何提示。
   - **白名单**: 消息直接放行。
   - **陌生人**: 拦截消息并缓存，达到阈值后自动回复提示语。
3. **LLM 请示**: 调用 LLM 以陆渊的身份向熙熙汇报访客信息，支持“准许/拒绝/观察”三档指令。
